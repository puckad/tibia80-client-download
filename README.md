# Tibia 8.0 Client

Ready-to-play Windows client.

## Download

Download `Tibia80-Client-Windows.zip` from the Releases section.

## Installation

1. Extract the complete ZIP to a folder.
2. Run `Play Tibia80.cmd`.

Keep every extracted file together. Windows may show a security prompt because this is a custom unsigned client.

## Connection

This package is currently configured for `127.0.0.1:7171`, which connects only when the game server runs on the same computer. The server address must be updated before remote players can connect.
